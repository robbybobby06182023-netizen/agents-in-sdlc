Elige un taller según lo que quieras aprender y hasta dónde quieras profundizar. **Primeros pasos** ofrece una introducción guiada a GitHub Copilot, mientras que **Desarrollo en situaciones reales** utiliza una aplicación completa y una lista de tareas de equipo para practicar flujos de trabajo orientados a producción.

## Primeros pasos

Empieza con una experiencia guiada y centrada que presenta las principales funciones de un producto de GitHub Copilot sin necesidad de disponer de una base de código.

### [Recorrido por la aplicación GitHub Copilot][first-steps-app]

Crea un Cuestionario espacial desde una carpeta vacía, publícalo en GitHub, implementa una incidencia, completa una revisión de Copilot, programa una automatización y explora un flujo de trabajo con Canvas.

### [Primeros pasos con GitHub Copilot CLI][first-steps-cli]

Crea el mismo Cuestionario espacial desde el terminal, revisa diferencias, ejecuta sesiones en paralelo en worktrees, planifica antes de editar y crea, combina y delega solicitudes de incorporación de cambios sin salir del shell.

### [Primeros pasos con Visual Studio Code][first-steps-vscode]

Crea el Cuestionario espacial en VS Code, pruébalo en el navegador integrado, publícalo con Control de código fuente, trabaja con incidencias y solicitudes de incorporación de cambios mediante las herramientas de GitHub y transfiere el trabajo a una sesión en la nube.

## Desarrollo en situaciones reales

Practica con GitHub Copilot en un ciclo de vida de desarrollo de software realista, usando la aplicación Tailspin Toys y su lista de tareas. Elige el entorno en el que quieras trabajar y, después, planifica, desarrolla, prueba, revisa y entrega cambios útiles.

### [Explora los talleres de desarrollo en situaciones reales][real-world-development]

Elige entre GitHub Copilot CLI, la aplicación GitHub Copilot, el agente de GitHub Copilot en la nube o Visual Studio Code.

> [!CAUTION]
> GitHub Copilot es probabilístico y no determinista, por lo que el código exacto y los archivos modificados pueden variar respecto a los ejemplos. Es normal que haya pequeñas diferencias.
>
> Si algo parece estar roto o no funciona correctamente durante un taller dirigido por un instructor, pide ayuda a un mentor.

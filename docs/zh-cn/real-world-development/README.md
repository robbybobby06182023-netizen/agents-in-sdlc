使用 GitHub Copilot 体验整个软件开发生命周期，涵盖真实场景、完整应用程序和共享待办事项。你将迭代规划变更、创建代码、测试行为、审查拉取请求，并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的一名新开发者，这是一家虚构公司，提供以开发者主题为核心的桌游众筹服务。团队的待办事项已经以 GitHub 议题的形式归档，等待你接手。它包括过滤和分页等功能工作，以及无障碍性和编码标准等质量改进。

## 选择你的环境

GitHub Copilot 会在你工作的环境中陪伴你。选择与你希望构建方式相匹配的环境。每个工作坊都从自己的设置开始，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能体助手。通过 Plan 和 Autopilot 模式、说明、技能、自定义智能体、Playwright MCP、Agent Merge 以及实用的斜杠命令来工作。

### [GitHub Copilot app][app]

运行并行智能体会话，切换会话模式，在桌面应用中协作处理画布，并管理 GitHub 议题和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub 议题分配给异步智能体，指导其工作，监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器即可使用 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。
